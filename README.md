## 🚀 Featured Projects

I believe in demonstrating technical expertise through practical applications. Here are some of my projects.

### 1. Kenya Infectious Disease Surveillance Dashboard

An interactive epidemiological surveillance application developed using R Shiny to explore infectious disease trends, geographical disease distribution, reported cases, mortality, recoveries and surveillance alert levels.

**Technologies:** R, Shiny, shinydashboard, ggplot2, Plotly, DT and Epidemiological Analytics.

- [🚀 Launch Live Dashboard](https://enochosen.shinyapps.io/kenya-infectious-disease-surveillance/)
- [💻 View Source Code](https://github.com/Biosticianenoch/kenya-infectious-disease-surveillance-dashboard)

### 2. Outbreak Investigation Dashboard

An interactive outbreak investigation platform designed to support epidemiological analysis through epidemic curves, person-place-time analysis, clinical outcomes, laboratory findings, exposure analysis and case-control investigation.

**Technologies:** R, Shiny, Statistical Analysis, ggplot2 and Epidemiology.

- [🚀 Launch Live Dashboard](https://enochosen.shinyapps.io/outbreak-investigation-dashboard/)
- [💻 View Source Code](https://github.com/Biosticianenoch/outbreak-investigation-dashboard)

### 3. Machine Learning & Predictive Analytics

Developing machine learning workflows for data-driven prediction, classification, model evaluation and analytical decision support.

**Technologies:** Python, R, Machine Learning, Statistical Modelling and Data Visualization.
